# 🍄 Mario Bash

An interactive Mario-inspired game designed to help users learn and practice basic Bash commands in a fun and engaging way.

Built in JavaScript, this project simulates a game environment where players interact using real command-line concepts, making it easier to transition to working with Ubuntu or Linux servers.

---

## 🎯 Purpose

Learning Bash can feel intimidating at first — especially when working directly on a terminal.

This project was created to:
- Make Bash learning more approachable
- Provide a safe environment to practice commands
- Bridge the gap between theory and real terminal usage
- Introduce command-line thinking through gamification

---

## 🧠 What this project demonstrates

- JavaScript application design
- Gamification of technical learning
- UX thinking applied to developer tools
- Translation of real-world concepts (Bash) into interactive systems
- Educational product mindset

---

## ⚙️ Tech Stack

- JavaScript
- HTML / CSS
- Browser-based execution

---

## 🎮 How it works

Players progress through a Mario-style environment by solving challenges using Bash-like commands.

Instead of traditional controls, users interact with the game through command inputs, reinforcing:
- Navigation commands (e.g. `cd`, `ls`)
- File operations
- Basic shell logic
